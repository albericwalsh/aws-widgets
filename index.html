AWS Widgets

Bibliothèque de Web Components réutilisables pour vos projets front‑end. Chaque widget est autonome et thémable via style.json.

Installation

Via CDN (jsDelivr) — stable via tag : 

import { initWidgets } from 'https://cdn.jsdelivr.net/gh/albericwalsh/aws-widgets@v0.1.4-dist/dist/aws-widgets.es.js';
        await initWidgets();
        window.awsWidgetsReady = true;

Via npm (après publication) :

npm install aws-widgets
import { initWidgets } from 'aws-widgets';
await initWidgets();

Composants (exemples)

  • <aws-button> — bouton stylé (variant, size).
  • <aws-input> — champs texte / number / email / password.
  • <aws-slider> — sélection numérique.
  • Et d'autres : table, selector, progress-circle, icon-button, context.

Publication

Les releases sont créées via un tag Git (`vX.Y.Z`). Le workflow CI build+attache les bundles à la Release. Voir BUILD_PUBLISH.md pour la procédure complète.

Théming depuis d'autres projets

Vous pouvez contrôler le thème des widgets depuis une application cliente (CDN ou npm). Exemple :

// via CDN
    import { initWidgets, setThemeObject, applyThemeToAllHosts, loadTheme } from 'https://cdn.jsdelivr.net/gh/albericwalsh/aws-widgets@v0.1.4-dist/dist/aws-widgets.es.js';
    await initWidgets();
    setThemeObject({ '--aws-accent': '#ef4444', '--aws-foreground': '#0f1724' });
    applyThemeToAllHosts();

    // or load packaged theme
    // const theme = await loadTheme(); setThemeObject(theme); applyThemeToAllHosts(theme);

Voir le README complet sur le dépôt pour plus de détails.
