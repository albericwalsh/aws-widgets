AWS Widgets

Bibliothèque de Web Components réutilisables pour vos projets front‑end. Chaque widget est autonome et thémable via style.json.

Installation

Via CDN (jsDelivr) — stable via tag : 

import { initWidgets } from 'https://cdn.jsdelivr.net/gh/albericwalsh/aws-widgets@v0.1.1/dist/aws-widgets.es.js';
await initWidgets();

Via npm (après publication) :

npm install aws-widgets
import { initWidgets } from 'aws-widgets';
await initWidgets();

Composants (exemples)

  • <aws-button> — bouton stylé (variant, size).
  • <aws-input> — champs texte / number / email / password.
  • <aws-slider> — sélection numérique.
  • Et d'autres : table, selector, progress-circle, icon-button, context.

Publication

Les releases sont créées via un tag Git (`vX.Y.Z`). Le workflow CI build+attache les bundles à la Release. Voir BUILD_PUBLISH.md pour la procédure complète.
